# LiftLog – demo

Interaktivni prototip mobilne aplikacije za praćenje treninga.

- `index.html` – aplikacija (jedan telefon, sve se klikće)
- `overview.html` – svi ekrani jedan pored drugog

## Objava na GitHub Pages
1. Napravi novi repozitorijum na GitHub-u i ubaci sve fajlove iz ovog foldera u njegov koren.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save.
3. Posle 1–2 minuta sajt je na `https://<korisnik>.github.io/<repo>/`, a pregled ekrana na `.../overview.html`.
